# IPL EDA Analysis

## 📌 Project Overview
Exploratory Data Analysis (EDA) of IPL datasets using Python (Pandas, Matplotlib, Seaborn).  
The project uncovers insights about matches, toss decisions, team performance, batting stats, and home vs away records.

## 🔹 Tasks Completed
- Data cleaning and preprocessing  
- Matches trend analysis  
- Toss decision patterns  
- Team wins and player of the match awards  
- Batting statistics (runs, strike rate, averages)  
- Home vs away performance comparison  
- Final summary with insights  

## 📊 Tools Used
- Python  
- Pandas  
- Matplotlib  
- Seaborn  
- Jupyter Notebook  

## 🎯 Key Insights
- MI and CSK are the most consistent winners.  
- Toss winners often choose to field first.  
- Certain players dominate “Player of the Match” awards.  
- Balanced teams succeed both at home and away.
